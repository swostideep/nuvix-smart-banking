# NuviX

Smart banking backend for middle-income consumers: build credit, manage debt,
and get access to credit that is actually better than what you already have.

Rewriting the earlier Express/MongoDB prototype in Django + DRF.

## Status

Early -- setting up the project skeleton.

## Stack

- Python 3.12, Django 5.1, Django REST Framework
- PostgreSQL, Redis, Celery
- Docker, pytest
